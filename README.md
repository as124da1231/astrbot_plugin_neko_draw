# 猫娘画图

![猫娘画图](./logo.png)

一款以 **APNG 双帧展示**为特色的 AstrBot 多提供商图片生成与编辑插件。

图片生成完成后，插件可以先快速展示猫娘首帧，再揭晓生成结果，并把两帧合成为一张 APNG 动图。内置首帧就是上图，也可以在 WebUI 中上传自己的图片替换。

除 APNG 外，插件还支持 WaveSpeed、RunningHub，以及兼容 OpenAI Images Generations 格式的服务，并提供模型模板、预设提示词、生成历史、图片下载、白名单、限流和独立 WebUI 控制台。

## APNG 双帧展示

开启 APNG 包装后的处理顺序：

```text
生成图片 → 猫娘首帧 → 生成结果 → APNG 动图 → 发送
```

默认设置：

| 设置 | 默认值 |
| --- | --- |
| APNG 动图包装 | 关闭 |
| 第一帧图片 | 插件内置猫娘图片 |
| 第一帧显示时长 | `100 ms` |
| 第二帧显示时长 | `20000 ms` |
| 循环次数 | `0`，无限循环 |
| 压缩优化 | 开启 |

进入 WebUI 的“发送增强”配置即可开启。未上传自定义首帧时，插件会自动使用内置的 `default_apng_frame.png`；上传后使用最后上传的一张图片。APNG 文件通常比静态图片更大，部分客户端可能只显示其中一帧。

## 主要功能

- 支持文生图和参考图编辑
- 支持 WaveSpeed、RunningHub 和 OpenAI 兼容接口
- 根据消息是否包含图片自动选择文生图或编辑模板
- 支持通过 `--model` 临时指定模型模板
- 支持在提示词中覆盖或增加请求参数
- 支持当前消息图片、回复消息图片和图片文件
- 支持预设提示词和 `{{user_text}}` 占位符
- 支持用户与群组白名单、多时间窗口限流
- 支持生成历史查询、详情查看、删除和图片下载
- 提供三种 WebUI 主题及响应式布局
- 支持猫娘首帧与生成结果的 APNG 双帧包装
- 支持普通图片、图片外显和 QQ 合并转发

## 内置模板类型

| 模板类型 | 用途 | 内置模型 |
| --- | --- | --- |
| WaveSpeed 文生图 | 使用 WaveSpeed API 生成图片 | `bytedance/seedream-v5.0-pro` |
| WaveSpeed 图片编辑 | 使用 WaveSpeed API 编辑参考图 | `bytedance/seedream-v5.0-pro/edit` |
| RunningHub 文生图 | 使用 RunningHub API 生成图片 | `seedream-v5-lite/text-to-image` |
| RunningHub 图片编辑 | 使用 RunningHub API 编辑参考图 | `dola-Seedream-5.0-pro/image-to-image` |
| OpenAI | 调用兼容 Images Generations 格式的接口 | `gpt-image-2` |

模板类型用于选择对应提供商的 API 地址和密钥。模板名称、模型名称、参考图字段和请求参数均可在 WebUI 中修改。

> OpenAI 模板目前调用图片生成接口。兼容服务需要支持 Bearer Token、JSON 请求，以及 `data[].url` 或 `data[].b64_json` 格式的响应。不同服务的实际兼容程度可能不同。

## 环境要求

- AstrBot `4.24.1` 或更高版本
- 至少一组可用的提供商 API 凭据

## 安装

插件标识为 `astrbot_plugin_neko_draw`。

可以通过 AstrBot 插件管理页面上传插件压缩包，或将插件目录放入：

```text
AstrBot/data/plugins/
```

安装后，在插件管理页面启用或重载“猫娘画图”。插件发布到 AstrBot 插件市场后，也可以直接从市场安装。

## API 配置

进入插件的 WebUI 控制台，在“API 密钥”页面填写需要使用的提供商。

| 配置项 | 说明 |
| --- | --- |
| WaveSpeed API Key | 从 WaveSpeed 控制台获取 |
| WaveSpeed Base URL | 默认 `https://api.wavespeed.ai/api/v3` |
| RunningHub API Key | 从 RunningHub API Key 页面获取；需要具备所调用模型的权限 |
| RunningHub Base URL | 默认 `https://www.runninghub.cn/openapi/v2` |
| OpenAI 兼容 API Key | OpenAI 或兼容服务提供的密钥 |
| OpenAI 兼容 Base URL | 直接使用 OpenAI 时默认为 `https://api.openai.com/v1` |

API Key 属于敏感信息，请勿截图、公开或提交到代码仓库。

## 模型模板

每个模板代表一套可以独立调用的图片模型配置。

| 字段 | 说明 |
| --- | --- |
| 模板名称 | 供默认模型和 `--model` 参数引用，必须唯一 |
| 模板类型 | 决定使用的 API 地址和密钥 |
| 模型名 | 提供商定义的模型或接口路径 |
| 启用模板 | 控制模板是否可用 |
| 允许作为默认模型 | 控制模板是否参与默认模型选择 |
| 默认优先级 | 数字越小，默认选择优先级越高 |
| 参考图字段名 | 编辑模型使用的请求字段；文生图留空 |
| 参考图数量上限 | 单次请求允许使用的参考图数量 |
| 提示词最小长度 | 提交前的提示词长度限制 |
| 请求参数 | 发送给模型接口的附加参数 |

模板名称和预设触发词都必须唯一。保存配置时如果检测到重复项，WebUI 会拒绝保存并显示重复名称。

不同模型接受的参数可能不同，请以对应提供商当前的模型接口文档为准。

## 基本使用

| 命令 | 说明 |
| --- | --- |
| `猫娘画图 <提示词>` | 生成图片；消息包含参考图时自动选择编辑模板 |
| `猫娘改图 <提示词>` | 使用默认编辑模板处理参考图 |
| `--model <模板名>` | 临时指定模型模板 |
| `--参数名 <值>` | 覆盖模板参数或增加新参数 |

文生图示例：

```text
猫娘画图 黄昏海边，海浪拍打礁石，电影感写实摄影 --aspect_ratio 16:9 --resolution 2k
```

图片编辑示例：

```text
猫娘改图 把图片中的人物改成赛博朋克风格
```

图片编辑需要随消息发送图片，或者回复一条包含图片的消息。

指定 RunningHub 模板：

```text
猫娘画图 像素风角色 --model rh_seedream_lite
```

参数值会进行基础类型转换：

- `true`、`false` 转换为布尔值
- 数字文本转换为数字
- 无值参数视为 `true`
- 其他内容保留为文本

## 预设提示词

预设提示词可以在 WebUI 中添加和修改，也可以通过管理员命令维护。

| 命令 | 说明 |
| --- | --- |
| `/猫娘添加 <触发词> <提示词内容>` | 添加或更新预设 |
| `/猫娘删除 <触发词>` | 删除预设 |
| `/猫娘列表` | 查看预设触发词 |
| `/猫娘提示词 <触发词>` | 查看预设详情 |

预设内容可以使用 `{{user_text}}`，调用时会替换为用户输入。预设还可以配置固定参考图，并决定它位于用户图片之前或之后。

## 白名单

白名单默认关闭。启用后，只有指定用户或群组可以使用绘图功能。

| 命令 | 说明 |
| --- | --- |
| `/猫娘白名单添加 <用户或群组> <ID>` | 添加白名单 |
| `/猫娘白名单删除 <用户或群组> <ID>` | 删除白名单 |
| `/猫娘白名单列表` | 查看白名单 |

白名单和预设管理命令仅限 AstrBot 管理员使用。

## 生成历史

WebUI 会记录成功和失败的生成任务，包括用户、群组、提示词、模板、提供商、模型、请求参数、参考图数量、生成耗时、状态和错误信息。

成功生成的图片可以在历史详情中预览和下载。历史记录支持筛选、分页、单条删除和全部清空。

## 输出设置

猫娘画图支持普通图片消息、@ 触发者、APNG 动图包装、图片外显文案和 QQ 合并转发消息。

APNG 默认关闭；开启后使用内置猫娘首帧，也可以上传自定义首帧。第一帧、第二帧停留时间，循环次数和压缩优化均可独立设置。

图片外显和合并转发依赖 `aiocqhttp` 平台。其他平台不支持时会自动回退为普通图片。

## 限流与网络

插件支持单用户多时间窗口限流、限流白名单、最大并发任务数、WaveSpeed 429 指数退避重试、请求代理、轮询间隔和任务超时。

不同账户和服务套餐的并发额度可能不同，请根据提供商控制台显示的实际额度设置最大并发数。

## 数据存储

生成图片、历史记录、预设提示词和白名单保存在 AstrBot 分配的插件数据目录中。更新插件时不应删除该目录；卸载或清理数据前，请先备份需要保留的内容。

## 注意事项

- 图片生成可能产生第三方 API 费用
- 模型名称、参数、价格和可用性可能由提供商调整
- RunningHub 不同模型接口使用的参数名称可能不同
- 文生图模板收到图片时会忽略参考图
- 编辑模板没有收到参考图时会提示用户补充图片
- 参考图会在提交前转换为提供商支持的 URL 或 Data URI
- 请确保生成内容符合所使用平台的服务条款和当地法律法规
